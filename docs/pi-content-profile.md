# Native Pi content selection

Pi now receives content only by default. Profiles select native skills and plain
instructions at projection time. The package has no executable extension or
custom configuration layer. `local-development-default` selects only
`semantic-ratchet`; an explicit supported profile can select additional content.

The public procedures are on [Mintlify](https://slopsentral.michne.com/guides/pi).
The [migration reference](https://slopsentral.michne.com/reference/pi-migration)
classifies each retired runtime responsibility and its replacement or removal.
The [Agent Skills specification](https://agentskills.io/specification) defines
the skill format consumed by the supported native hosts.
