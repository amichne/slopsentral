# Product brief

## Description

Slopsentral supplies five plugins for source-backed software engineering.
Its procedures connect invariant design, executable evidence, and linked OKF explanations.
The public site presents canonical repository documents through Mintlify.

## Primary audience

Developers use the site to select plugins, install a host, and understand the engineering practice.
Maintainers use it to change authored source, examine evidence, and deliver qualified packages.
These reader roles come from the repository's current README and documentation index.

## Jobs to be done

- Select the plugin capabilities for a concrete software task.
- Install and manage those capabilities for an explicit host.
- Connect a software change to its source owners, executable evidence, and explanation.
- Adopt the same documentation procedure in another project.
- Examine source, package, and live-site evidence before a delivery claim.

## Motivation

The user asks for linked OKF knowledge, source coverage, freshness checks, portability, and direct use of the distributed practice.
Canonical documents own the prose.
The public site remains a checked consumer of those documents.
Generated pages and a successful build do not establish semantic accuracy or reader comprehension.
