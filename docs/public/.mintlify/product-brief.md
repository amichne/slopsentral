# Product brief

## Description
Repository-owned engineering skills delivered through native Codex, Copilot and
Pi primitives, with one qualified source and usable release set.

## Primary audience
Developers installing skills and maintainers qualifying source changes.

## Jobs to be done
Install without a source checkout, discover the intended content, update safely,
and recover configuration. Maintainers verify and publish one attributable set.

## Motivation
User direction: remove the custom Pi runtime and outside workflow bundles;
make setup visible and keep public documentation on this Mintlify site.
