Software Engineering supplies one focused design skill, `semantic-ratchet`.
The host discovers its standard `SKILL.md` and loads its references for the task.
The plugin supplies no automatic hook, Stop gate, language policy, or local service.

## Design principles

Constrain external primitives before composition.
Use enums for finite domains and closed variants for case-specific data.
Pass refined values to consumers that need the established fact.
Keep unchecked construction under the invariant owner.

Each conditional predicate answers one yes-or-no question about a known value.
Separate parsing, membership, normalization, and comparison.
A predicate returns true or false.
A refinement returns a stronger value or a finite failure.
Exhaustive case selection and traversal can handle several alternatives.

Keep decisions pure and external effects explicit.
Examine an accepted case and the nearest rejected case with the project tools.
Compiler success does not prove an external effect or model behavior.

## General workflows

Use the host workflow and repository tools for implementation and delivery.

Developer Tooling keeps Python automation and tool authoring.
