Repository Knowledge supplies four skills for documents and source-backed repository work.
For documentation alone, this plugin supplies the needed procedures.
Knowledge generation remains optional during routine code work.

## Skills

| Skill | Purpose |
| --- | --- |
| `technical-documentation` | Structure pages, trace source claims, and maintain documentation sites. |
| `controlled-technical-writing` | Apply stable terms and the shared local prose assessment. |
| `code-knowledge-base` | Create or refresh source-backed concepts and signature indexes. |
| `local-repository-navigation` | Use repository navigation and inspect its local setup. |

## Ownership and hooks

Technical Documentation owns structure, source coverage, navigation, and reader actions.
Controlled Technical Writing owns the shared prose procedure.
Use both skills for a site page.

The plugin selects `code-knowledge-drift` and `knowledge-overlay` hooks.
Their declarations do not prove that the host delivers or consumes their output.
A document or generated index remains evidence to examine against source.
It does not replace the current code or contract as authority.

## Local prose tools

The writing skill bundles Vale rules and an installer for Vale 3.24.0.
The assessment accepts explicit Markdown, MDX, or text files.
It records input hashes, measurements, and prose findings.
Schema version 2 does not assess terminology.
It does not contact a hosted Vale service.

Use the [prose guide](/guides/controlled-writing) for the commands and result meanings.
The [plugin manifest](https://github.com/amichne/slopsentral/blob/main/source/plugins/repository-knowledge/plugin.json) owns the selection.
