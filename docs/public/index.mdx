Slopsentral supplies five plugins for Codex and GitHub Copilot.
An optional in-repository Pi extension adapts the same skills and declared hooks.
A plugin groups capabilities for installation.
A skill gives an agent instructions and resources for a specific task.

Start with Software Engineering for constrained domain design.
Add Kotlin Engineering for Kotlin and Gradle.
For documentation alone, choose Repository Knowledge.

## State the outcome

Give the agent a concrete task and its limits.
The agent selects the procedures within your installed plugins.

```text
Use Software Engineering and Kotlin Engineering.
Change this parser to reject an empty identifier.
Keep the public error contract.
Run the focused test and compiler rejection case.
Leave the changes local.
```

This prompt illustrates a request.
It does not record a completed result.

## Understand the evidence

Slopsentral prioritizes safety, correctness, proof, scope, pure functions, and atomic units.
Installation makes capabilities available.
It does not prove that a host consumed a hook or that a model obeyed a rule.

The [catalog](https://github.com/amichne/slopsentral/blob/main/source/CATALOG.md) lists the current identities.
The [architecture](/reference/architecture) explains ownership and evidence limits.
