A workflow profile declares a repeatable plugin selection and its policies.
Normal plugin use relies on the host marketplace.
Slopsentral supplies no global launcher or automatic repository-profile hook.

## Explicit lifecycle

From a prepared checkout, inspect a selection with:

```bash
node tools/catalog.mjs --profile documentation-default --json
node tools/profile-lifecycle.mjs plan --profile documentation-default
```

The catalog reports the selection from source.
The lifecycle plan also reads Codex configuration and inventory.
It does not apply the plan.

An explicit `apply` can add the marketplace, install selected plugins, and create a named Codex configuration.
The default policy disables unselected Slopsentral plugins in that configuration.
It preserves foreign plugins and does not uninstall the unselected plugins.

The lifecycle needs Codex CLI 0.134.0 or later.
It refuses an unmanaged target file unless the request explicitly permits replacement.
It never writes the host's hook trust state.

## Saved transactions

The lifecycle keeps file preimages and returns a transaction manifest.
Rollback uses that exact manifest and the recorded target identity.
If later work changes the target, rollback reports `PROFILE_CONFLICT` and writes nothing.

Rollback covers the generated configuration file.
It does not reverse marketplace or plugin installation effects.
The [lifecycle document](https://github.com/amichne/slopsentral/blob/main/docs/profile-lifecycle.md) supplies apply and rollback commands.
The [authored profiles](https://github.com/amichne/slopsentral/tree/main/source/profiles) own the selections.
