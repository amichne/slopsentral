Install the `slopsentral` command, then select your host and plugins.
Consumers need no Slopsentral checkout, npm, or Pkl.

## Prerequisites

Use macOS or Linux for the shell bootstrap.
The command needs uv and Python 3.12 or 3.13.
The bootstrap installs pinned uv when it is absent. uv can download Python.
If an existing uv is too old, update it before installation.

Install your coding host first.
Codex and Copilot need their CLI commands on `PATH`.
Pi needs its command, Node.js 22.19 or later, curl, and system tar.

## Install

Run the bootstrap from a release that includes the command assets:

```sh
bash -o pipefail -c 'curl -fsSL https://github.com/amichne/slopsentral/releases/latest/download/install.sh | sh'
```

If `~/.local/bin` is absent from `PATH`, add it:

```sh
export PATH="$HOME/.local/bin:$PATH"
```

Start guided setup:

```sh
slopsentral setup
```

Choose the bulk action and hosts, then accept the action summary.
For selected plugins, use an explicit command instead:

```sh
slopsentral install --host codex --plugin software-engineering --plugin kotlin-engineering
slopsentral install --host copilot --plugin software-engineering
slopsentral install --host amp --plugin developer-tooling
slopsentral install --host pi
```

[What you get](/index) explains the five choices.
Codex, Copilot, and Amp also accept `--all` instead of `--plugin`.
Pi installs the aggregate package and rejects `--plugin`.
Restart Pi after installation.

## Update or remove

Use the same host and plugin selection:

```sh
slopsentral update --host codex --plugin software-engineering
slopsentral remove --host codex --plugin software-engineering
slopsentral self update
slopsentral self remove
```

Replace `codex` with `copilot` or `amp` for those hosts.
For Pi, use `slopsentral update --host pi` or `slopsentral remove --host pi`.
Self-removal preserves installed host plugins.

## Special cases

Use the [command reference](/reference/command) for automation, versions, selector controls, failures, and the Kotlin layout detector.
Use [Pi setup and recovery](/guides/pi) for project scope, direct bootstrap, and rollback.
Use [checkout setup](/developers/contribute#prepare-a-checkout) to install from source.

The command uses native Codex and Copilot operations, managed Amp links, and the native Pi installer.
Installation does not prove that a host discovers or uses the installed instructions.

## Maintainer change contract

Read this section when changing the implementation or packaging of this owner.
Consumer installation alone does not require a source rewrite.

`install.sh` owns the minimal shell bootstrap for the `slopsentral` command.
It downloads pinned uv only when `uv` is absent from `PATH`.
`tools/slopsentral.py` owns the locked Python command and its installation, update, and removal operations.
The checkout launcher for `slopsentral audit` uses `uv.toml` and `.python-version`.
The installed launcher runs the audit with `uv run --no-project`.
Explicit host operations use `--host`.
Codex, Copilot, and Amp accept `--plugin` selections or `--all` for installation and updates.
`slopsentral setup` selects a bulk action and harnesses interactively.
Bulk commands without `--host` open the harness selector. Removal keeps explicit selections.
Use native Codex and Copilot commands for their host configuration.
Amp uses managed links to release archives. Pi delegates to `tools/setup-pi.mts`.
`tools/setup_assets.py` keeps the bootstrap, Python script, lock, and setup receipt.
`source/schemas/pi/setup.schema.json` owns the receipt contract.
Keep historical two-file, five-file, and seven-file inventories valid.
The nine-file inventory includes the two audit modules.
The command bundles the canonical Kotlin detector and its lock from `source/hooks/`.
Keep layout findings advisory. Inspection failures must return a nonzero status.
Reject partial inventories and duplicate filenames.
Keep upload and download lists in `.github/workflows/release-pi.yml` synchronized with that inventory.
Preserve edited managed files, foreign paths, and disabled plugin choices.
Keep installed copies and cached archives outside authored source.
Run `uv run --locked pytest tools/python_checks/test_slopsentral.py tools/python_checks/test_setup_assets.py` after command changes.
