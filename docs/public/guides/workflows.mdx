Use repository instructions and the host's native tools for general implementation, debugging, review, Git, and CI.
Slopsentral does not install another marketplace or an outside workflow bundle.

| Task | Local owner |
| --- | --- |
| Domain values, pure predicates, and exhaustive cases | `semantic-ratchet` in Software Engineering |
| Git, CI, PR delivery, and TDD | Standalone source skills in `source/skills/` |
| Python automation and tool authoring | Developer Tooling |
| Documentation and repository evidence | Repository Knowledge |

The [catalog](/reference/catalog) lists each installable composition and standalone skill.
The default Software Engineering plugin supplies one standard skill without an executable hook or local service.

Runtime documentation remains with its vendor because host APIs and compilers define those contracts.
The [external reference inventory](/reference/external-references) records each retained URL and its purpose.
The [release guide](/reference/releases) defines the canonical assets and native Pi content scope.
