# Personal configuration

Developer Tooling owns personal configuration procedures and reusable CLI design.
Use Personal Setup Management only for an explicit configuration task.
The skill examines the live wrapper, Git metadata, public source, and installed consumers before a change.
A historical dotfiles layout cannot establish current authority.

Use CLI Creator for a requested personal command.
New automation uses locked uv Python. Kotlin projects keep their own toolchains.
The retained JavaScript sample illustrates finite JSON results and `--teach` behavior.
Its parent-shell adapter supplies history that the child process cannot read.

Run the sample from the source checkout:

```text
node source/skills/cli-creator/assets/personal-size.mjs --help
node source/skills/cli-creator/assets/personal-size.mjs --min-bytes 1048576 --json
node source/skills/cli-creator/assets/personal-size.mjs --teach "Explain this tool" --teach-preview
```

The preview describes its exact source files, hashes, directory context, and available history.
It invokes no assistant. The sample uses literal arguments and a finite result schema.
A preview grants no authority to change installed configuration or invoke an external adapter.
