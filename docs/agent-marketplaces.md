# Native harnesses

Codex and Copilot consume their projected marketplaces. Pi consumes native skills
and scoped instructions without an executable extension. Profiles select content
at authoring time; Pi rejects unsupported hook and invocation guarantees.

See [installation](https://slopsentral.michne.com/guides/install),
[architecture](https://slopsentral.michne.com/reference/architecture), and
[Pi migration](https://slopsentral.michne.com/reference/pi-migration) on Mintlify.
