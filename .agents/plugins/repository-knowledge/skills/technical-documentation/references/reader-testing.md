# Reader Testing

Assess whether a document supports its intended action without the original conversation.
A prose measurement does not prove comprehension.

## Questions

Derive questions from the reader's task:

- What problem or decision does the document address?
- What action does the reader take next?
- Which statements are requirements, and which are advice?
- Which source owns each material claim?
- Which command or evidence supports the result?
- Which prerequisites does the document assume?
- Which ambiguity can change the reader's action?

## Review

Give an independent reader only the document and questions when that review is available and authorized.
Otherwise, assess the document yourself without facts from the conversation.
Label that result as a simulated review.

Record answers found directly, inferred answers, undefined terms, unsupported claims, contradictions, and unresolved questions.
For each issue, identify its owner section and add the smallest source-backed correction.
Remove workarounds that depend on conversation context.
Repeat each affected question after the edit.

Report who or what assessed the document and the unresolved questions.
Do not present simulated answers as evidence from a human reader.
