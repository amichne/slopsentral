# Delegation

Use available agents only when an independent result justifies the coordination cost.
Give each worker an outcome, source inputs, allowed files, allowed effects, oracle, and stop condition.
Keep one writer for each mutable surface. Keep coupled decisions with one owner.
A delegated task grants no extra authority.

Continue independent work while a worker handles its assigned surface.
Inspect the actual diff and proof at handoff. Resolve conflicts before combined tests.
Do not infer success from the worker message.
Keep proposed checks, executed results, and unresolved gaps separate.
