# Glossary Entry Template

Complete the fields from inspected sources before you register the term.
Remove placeholders from the final entry.
Keep unresolved candidates outside the active glossary.

```markdown
- §TERM§: [Known class of thing and the property that distinguishes this concept.]
  - Known synonyms: none
  - Domain usage: [Current external source, exact section, meaning, and date examined.]
  - Local evidence: [Repository path, symbol or section, and revision.]
  - Local scope: [The product, version, actor, or lifecycle that limits this definition.]
  - Example: [A source-backed instance that satisfies the definition.]
  - Distinction: [The nearest different concept and the property that separates it.]
  - Synonym evidence: none
```

For a supported alternate label, record its source and the scope of equivalence in `Synonym evidence`.
Put the exact label in `Known synonyms` or a code span within the evidence.
An empty synonym list is valid and needs no invented entries.
