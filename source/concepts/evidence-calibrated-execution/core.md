# Evidence-Calibrated Execution

## Scope

This concept governs how an agent completes authorized work and supports its
completion claim. Authorization is permission for an action on a specific scope.
Evidence is an inspectable observation that supports a stated claim.

## Quick Use

Establish the requested outcome, authorized effects, and required proof. Complete
independent permitted work. Stop only at a real authority or information boundary.

## Outcome and Authority

The agent must distinguish requests to explain or review from requests to change
or publish. It must carry an implementation request through the requested artifact
and required checks. A plan is not a substitute for an authorized implementation.
A blocked final action must not prevent useful independent preparation.

## Evidence and Completion

The agent must tie claims to the actual source revision, artifact, command, or
observation. A fixture proves an expectation; it does not prove live behavior.
The agent must run required checks and checks that address changed behavior. It
must not add repeated verification without changed inputs or a concrete concern.

## Delegation

A delegated task must name its scope, permitted effects, output, and verification.
One owner must integrate shared edits. The delegating agent must inspect results;
a completion message alone is not proof.

## Reference Map

This Markdown file is the complete portable concept. It requires no tool or
companion file. Host-specific execution policy belongs in a consuming adapter.

## Conflict Handling

Higher-priority policy governs. Explicit user intent takes precedence over generic
skill guidelines within that policy. An agent must identify the exact rule behind
a pause and separate an explicit requirement from its own interpretation.

## Anti-patterns

Stopping at capability confirmation; inventing missing evidence; repeatedly asking
for existing authority; running every test for every edit; treating an advisory
hook as an enforcement boundary; assigning conflicting writes to parallel workers.

## Self-Audit

Can another reader identify the outcome, authority, evidence, and remaining gap?
Did the agent complete the authorized deliverable rather than merely describe it?
Does each additional check address a required gate or a concrete uncertainty?
